# mano-app — AI agent instrukcijos

Šios instrukcijos taikomos dirbant su mano-app projektu.

## Projekto kontekstas
Prieš keičiant kodą perskaityti `context.md`. kolkas ignoruok.
Visada teikti pirmenybę naujausiam projekto kodui, jei jis skiriasi nuo senesnės dokumentacijos.

## Technologijos
- Naudoti React + Vite.
- Naudoti JavaScript ir JSX; nekonvertuoti į TypeScript.
- Nepridėti Tailwind CSS ar CSS Modules, nebent to aiškiai paprašyta.
- Komponentų stilius laikyti atskiruose `.css` failuose.
- React komponentus laikyti `src/` aplanke, nebent sąmoningai pertvarkoma projekto struktūra.

## Kodo pakeitimai
- Prieš redaguojant failą, jį peržiūrėti.
- Neišgalvoti neegzistuojančios projekto logikos ar API.
- Išlaikyti esamą funkcionalumą, nebent aiškiai prašoma jį keisti.
- Vengti nesusijusių pertvarkymų ir nereikalingų priklausomybių.
- Rinktis paprastus sprendimus.
- Naudoti funkcinius React komponentus ir React hooks.

## Dizainas
Išlaikyti dabartinį mano-app stilių:
- šviesus, pilkšvai žalsvas fonas;
- žalsvai melsvas pagrindinis akcentas ir žalia atliktų vizitų spalva;
- tamsus pagrindinis tekstas, pilkas antrinis tekstas;
- švelnūs kortelių rėmeliai ir apvalinti kampai;
- minimalistinis, responsyvus išdėstymas.

Nekeisti bendros dizaino krypties, nebent to aiškiai prašoma. Naujesnis kodas svarbesnis už pasenusius dizaino aprašus.

## Sąsajos kalba
- Naudotojui skirtus tekstus rašyti lietuviškai, nebent prašoma kitaip.
- Žymas ir pranešimus formuluoti trumpai ir aiškiai.
- Kai įmanoma, išlaikyti esamą terminiją.

## Prieš baigiant
Patikrinti, kad:
1. Kodas atitinka esamą projekto struktūrą.
2. Esamas funkcionalumas išlaikytas.
3. Nepridėta nereikalingų priklausomybių.
4. Sąsaja išlieka responsyvi.
5. Importai ir failų keliai teisingi.

## Pateikiant pakeitimus
- Trumpai paaiškinti, kas pakeista.
- Nurodyti kiekvieno naujo ar pakeisto failo tikslų kelią.
- Jei kodą reikia įklijuoti rankiniu būdu, pateikti visą atnaujintą failą.
- Aiškiai nurodyti, ar failą sukurti, ar pakeisti.
- Pateikti trumpą būdą rezultatui patikrinti.
